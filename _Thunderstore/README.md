# AppearancePlus Emotes
Maintained by: [**ZeinaKC**](https://thunderstore.io/c/atlyss/p/ZeinaKC/). (Other contributors are to be noted)\
Adds five emotes from an old AppearancePlus beta build, few of which were exported from older ATLYSS iterations.
- **Default Dance**
- **Salute**
- **Victory**
- **Present** (Jack-O-Pose basically)
- **OG Taunt**
## Contacts & Help
- If you need to contact us or need general modding help, join the [**ATLYSS Modding Central**](https://discord.gg/hQceRJ7pEW) Discord server.
- To create your own emote pack, follow WolfKann's [**Atlyss Custom Emotes**](https://github.com/WolfKann/Atlyss-Custom-Emotes/wiki) guide.
- Source assets available on [**Github**](https://github.com/AtlyssModding/AppearancePlus-Emotes).
